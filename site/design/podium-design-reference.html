Features

01

Cross-harness delivery

Write canonical artifacts once. Automatically translate into the format your runtime expects.

02

Domains and subdomains

Easy artifact maintenance and discoverability through the use of domains and sub-domains.

03

Selective materialization

Sync a subset of the catalog into a workspace. Define profiles to quickly and seamlessly switch between scopes.

04

Progressive discovery

Minimalistic set of tools for agents to traverse domains and find artifacts, materializing artifacts (including bundled files) lazily as they are needed.

05

Layered composition

Compose the catalog from multiple independent sources with deterministic merge and explicit precedence.

06

Access control

Declare who can see what: public, org-wide, scoped to OIDC groups, or specific users.

Getting Started  /  Quickstart

Quickstart

This page shows the filesystem setup. The catalog is a local directory, and podium sync writes harness-native files into a project.

Podium is at 0.1.x, an early release. Surface and behavior may still shift before 1.0; see Implementation status.

01Install the CLI

Pick the channel that matches your platform. Each option installs the three Podium binaries on PATH.

Homebrew ScoopBinarySource 
$ brew tap lennylabs/tap
$ brew install podium
$ podium version

02Tell Podium where the catalog lives

From the project that will consume the artifacts, point Podium at that directory and set Claude Code as the default harness.

$ mkdir -p ~/podium-artifacts/personal
$ podium init --registry ~/podium-artifacts/ --harness claude-code

That writes .podium/sync.yaml with two defaults: a registry pointing at the directory and a harness telling Podium how to format outputs.

03Write your first skill

A skill is a directory with two manifest files at its root: SKILL.md for agent-facing content and ARTIFACT.md for Podium metadata.

SKILL.md
---
name: greet
description: Greet the user by
  name and tell them the date.
license: MIT
---
ARTIFACT.md
---
type: skill
version: 1.0.0
tags: [demo, hello-world]
sensitivity: low
---

04Materialize

$ podium sync

adapter: claude-code
target:  /Users/alice/myproject
artifacts:
  - personal/hello/greet  [podium-artifacts]
      .claude/skills/greet/SKILL.md

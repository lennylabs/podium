SKILLv2.3.0

Review a service for span coverage before it ships. Checks naming conventions, required attributes, and sampling decisions against the platform's OTLP contract.

RenderedFrontmatterAuthored sourceResources5

When to use this

Run before a service's first production deploy, and again whenever its span names change. The review is read-only: it never edits instrumentation, it reports what is missing and why it matters.

Procedure

  1. Read otel.yaml and list every configured exporter.
  2. For each HTTP handler, check that the span name is the route template, not the resolved path.
  3. Flag any span carrying a high-cardinality attribute; suggest a bucketed replacement.
resources/span-checklist.md
# required attributes
service.name, service.version, deployment.environment
# forbidden
user.email, request.body, any raw id

Escalate to the platform team when a service needs an exemption from the sampling policy.

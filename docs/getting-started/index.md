# Getting Started

The pages in this section introduce Podium in the order below. Each page
assumes the ones before it. A reader who wants to try Podium before reading
about it starts with the [quickstart](quickstart), which needs only the CLI
and a local directory.

| Order | Page | What it covers | Time |
|:--|:--|:--|:--|
| 1 | [Why Podium](why-podium) | The features, when Podium applies, when a simpler alternative is enough, and how Podium compares to adjacent products. | ~10 minutes |
| 2 | [Quickstart](quickstart) | Installing the CLI, writing one skill in a local catalog, materializing it into Claude Code and Cursor, and using it. | ~5 minutes |
| 3 | [Concepts](concepts) | The vocabulary the rest of the documentation links to, from registry and artifact to materialization and the meta-tools. | ~15 minutes |
| 4 | [How it works](how-it-works) | The components, where each one runs, where state lives, and how an artifact travels from the registry to a harness. | ~15 minutes |

The [documentation home](../overview) lists the guides for authoring,
consuming, deployment, and reference that follow this section.
